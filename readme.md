# Personal Portfolio Website

This repository contains a simple personal portfolio website created using only HTML, with no CSS or JavaScript.

## Project Details

- **Title:** AKSHARA PANJALA - Portfolio
- **Author:** AKSHARA PANJALA
- **Course:** BS MS Computer Science
- **College:** Vishwa Vishwani Institute of Systems and Management

## Files

- `index.html` - The main portfolio page with semantic HTML structure.
- `images/akshara-panjala.jpg` - The profile image displayed in the About section.

## Features

- Semantic HTML5 structure with `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`
- `<header>` section with name and introduction
- `<nav>` with internal links to sections
- `<main>` containing `About`, `Skills`, and `Contact` sections
- Working contact form with Name, Email, Message, and Submit button
- Image included using only HTML attributes and basic structure

## How to View

Open `index.html` in a web browser to view the portfolio page.

## Notes

- No CSS or JavaScript is used in this project.
- All styling and layout are achieved through HTML structure only.
